# 0001 主题契约 v2：按层定角色，同类少值

- 日期：2026-11-22
- 状态：已采纳（2026-11-22）
- 规范：[`docs/specs/theme-contract-v2.md`](../specs/theme-contract-v2.md)

## 背景

到 #256 为止，主题为了让 6 套主题（含 apple、material、winui 三套原生主题）都对上官方外观，长出了很多以组件命名的值：

- `cssVars.light` 有 74 个颜色角色，`cssVars.theme` 里还有 11 个颜色键，其中不少在多数主题里只是别的角色的 alias；
- 圆角 8 个，按组件族命名；
- default 指针档有 7 个高度、4 个图标尺寸；
- 8 组控件几何共 100 多个值，在 4 套主题里完全相同；
- finish 27 个，default 主题有 28 条不同的阴影。

主题作者要填的东西太多，同类东西的值也不统一。改它会影响所有自定义主题和 registry 产物，回退代价高，所以记下理由。

## 决定

1. 主题角色按层与语义命名，不按组件命名；纯 alias 删除，按主题不同的选择移进该主题的 finish 或组件的控件预设。
2. NSH / shadcn 的 31 个 A 层槽（含 `sidebar-*`、`radius`）作为对外格式全部保留，在源码里写成 alias，本库组件不读。
3. 平台固定的身份色（macOS 红绿灯）属于组件，这是"颜色只来自主题"（P3）的唯一例外。
4. 圆角收为 `control` / `container` / `modal` 三个角色，另加一个按钮胶囊开关；内层圆角同心推出（#253 方案 B）。
5. 尺度同类少值：高度、图标各 3 档，间距在 4 的网格上，字阶不倒挂、行高为整数 px，弹簧 3 个。平台官方确有的例外要写出处。
6. 控件几何从主题移进组件，主题只选 `controls: "base" | "material" | "winui"`。
7. finish 按层收为 9 层 + 3 种状态，阴影是每种外观最多 4 档的 elevation 刻度，平涂主题的渐变写 `null`。
8. 材质是 finish 上的枚举 `none` / `glass` / `acrylic`，配方集中在 `packages/theme`，每个配方都自带 fallback。

## 理由

- **同类少值是界面的规律。** 圆角、高度、间距、阴影各成一条短刻度，界面才有韵律；主题作者也只做少数几个选择。
- **组件名进了主题，主题就跟着组件一起膨胀。** 每加一个组件就要加角色，而主题作者看不出该填什么。按层命名的角色，从名字就能知道含义。
- **控件形态是组件的事。** 三种形态（base、M3、WinUI 3）是有限集合；把它们写成组件里的预设，主题作者不用再照抄 100 多个数，也不会出现填了一半的第四种形态。
- **A 层是对外契约。** NSH 的 `Theme` 就是 shadcn 的 token，缺槽会退回 neutral 灰，应用里写的 `bg-sidebar` 会变色，所以不能删。
- **材质靠配方保证 fallback。** #251、#252 两次都是"某个平台不画模糊，结果透底"；由配方统一展开，fallback 就不会漏写。

## 不采纳的方案

- **只删纯 alias，其余不动。** 成本最低，但组件命名的角色和控件几何还留在主题里，主题作者要做的选择几乎没变少。
- **删掉 `sidebar-*` 等 A 层槽。** 主题更干净，但会改变使用本库主题的应用的外观，而且 NSH 的格式不归我们管。
- **控件几何保留在主题里，只是减少键数。** 主题作者仍然要懂每个控件的几何；三种形态的数值也仍会在多套主题里重复。
- **材质按层固定（例如 overlay 一律用玻璃）。** 实现更简单，但 apple 在 `raised` 上也用玻璃（#252），按层固定会丢掉这个按主题的选择。
- **用 CSS 模拟 Acrylic 的噪点与 luminosity 混合。** NSH 的 `backdropFilter` 只支持模糊，也没有 SVG 滤镜，做不出来；记为差异。

## 后果

- 每一步都是 breaking change，自定义主题要按 `CHANGELOG.md` 迁移，不提供 alias 或兼容层。
- `theme-roles.md`、`native-themes.md`、`design-tokens.md`、`design-semantics.md`、`GLOSSARY.md`（控件预设、材质、elevation 等词）、`ARCHITECTURE.md`（P3 例外）在对应步骤里改成新的事实。
- `check:theme` / `theme-lint` 要执行这些规则：刻度上的值、字阶顺序、finish 字段集合、材质枚举。
