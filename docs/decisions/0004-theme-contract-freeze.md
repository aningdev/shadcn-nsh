# 0004 主题契约冻结为 v3：只降级，不扩张

- 日期：2026-11-24
- 状态：已采纳（2026-11-24）；第 1、3 条对“把控件形态枚举换成数值槽”这一次重构的限制已由 [0013](0013-one-contract-value-slots.md) 取代（不为一套主题加键、组件里不写主题分支这两条照旧）
- 规范：[`docs/specs/theme-contract-v2.md`](../specs/theme-contract-v2.md) 第 20 节（冻结与降级）

## 背景

契约（`semantics.json` 的 schema：finish 的层与字段、颜色与圆角阴影角色、控件维度、动效）每次为迁就一套主题就长一点：为 winui 的日历加 `mark`、为日期选择器加 `trigger`、为轮播加 `arrow`，再为 material 与 winui 的日格加 `hint` 与 `cellShape`（#293）；这些项最后又按原则 6 降级删掉（第 11.7 节）。一次 schema 改动牵动 6 套主题、生成器、`theme-lint`、文档与每个读它的组件，回退代价高；而功能上没有任何东西阻止下一次。

## 决定

1. **冻结在 contract v3**：最后四件是 #340（删掉 `cells`、`ripple` 与弹簧）、#293 P6（`motion.state` 等动效角色）、#357（`fill` 层；开关的 `checked-*` 字段）、#358（`dimension.control.selection` 增加取值 `plate`：`pill` 是 default 的胶囊，`plate` 是 shadcn、solid-glass、apple 里按控件圆角切齐的块）。它们落地即冻结；在那之前，schema 只有它们能改。
2. 冻结之后，一套主题表达不了的外观**降级**：在契约已有的键里改值，向最近的一档靠；与原生的差别记进 [`native-themes.md`](../specs/native-themes.md) 第 3.6 节的差异表。现在写主题也照这个来，冻结只是让它不可绕过。
3. **不扩张**：不为一套主题新增键、层、字段，也不在组件里写这套主题的代码或分支。新的一层（finish）只给一种不同的**表面**，不给状态——状态是 finish 上的字段（`pressed-opacity`、`pressed-background`、`checked-*`）。
4. 例外：`default`（NSH Gallery）是官方 look，契约必须能完整表达它；其余五套（shadcn、solid-glass、apple、material、winui）可以降级。
5. 闸门：`bun run theme:diff --gate <base>` 在 diff 里有 `contract` 类改动（键的新增或删除，或共用源改动）且同一分支没有新增 `docs/decisions/*.md` 时失败。四件冻结工作自己的 PR 就是这个记录的例外，由本文件授权：给它打 `theme-contract-freeze` 标签，CI 就带上 `--freeze`；标签只有维护者能打，冻结完成后两者一起删掉。
6. 契约改动是 breaking change，`CHANGELOG.md` 的 `Unreleased` 由维护者写。

## 理由

- 扩张按每套主题的局部需求各付一次成本，收益只落在那一套；冻结后同样的需求改成值，改动面只在这套主题里。
- 契约是 6 套主题共同的词汇表。词汇表由最会要求的主题决定，另外 5 套就得跟着变，主题作者要懂的东西越滚越多。
- 降级有验收：差异表列着 gap，读者知道哪里不一样；多加一个维度不留下账。
- `default` 是官方 look，是五套原生主题之外的默认体验，被本库的文档、演示与截图依赖；契约表达不了它就等于冻结第一天就失真。
- 闸门带标签的例外，是因为四件冻结工作自己就要改 schema；让它们各写一份决策记录，只是把同一件事记四遍。

## 不采纳的方案

- **继续按每套主题扩张契约。** 每次都不大，但总量在涨，而且 #293 刚因扩张收回一批（第 11.7 节）。
- **今天就冻结（四件落地之前）。** 会冻进即将删掉的 `cells`、`ripple` 与弹簧，冻结后只能再开一个契约 PR，恰好是这一步要防的。
- **给 `default` 也降级。** 少一个例外、规则更整齐，但会让本库的默认外观向契约让步，方向反了。
- **例外只写进各主题 README。** 六处地方六种格式，读的人凑不出全貌；差异表是同一个地方、同样的列。
- **闸门不留门（四件冻结工作也照写记录）。** 规则更单纯，但那四份记录会各写一遍“见 0004”，闸门从此只给人添一步。
