# 0020 · Theme v5: TS Sparse Source of Truth, 25-Key `theme.json`, and Unified Feedback/Motion

- **Date**: 2026-11-26
- **Status**: Accepted
- **Supersedes**: `0004`, `0006`, `0007`, `0013`, `0019` (DTCG-as-source, 58-key `theme.json`, `semantics.json`, `finish-fields.ts`, and single-theme control slots)

> **Revision (2026-11-27)**: `cssVars.theme` always writes `font-sans` (default `system-ui`) and `font-mono` (default `monospace`). The layer radius keys are `radius-md`, `radius-lg`, and `radius-xl` (no `radius-control` / `radius-container` / `radius-modal` aliases). `radius` still equals the control radius (`radius-md`). `shape.control` / `shape.container` / `shape.modal` keep their names. `font.sans` and `font.mono` read the font keys. The decision text below records the contract as accepted on 2026-11-26.

## Context

Over Contracts v1–v4, the theme system accumulated three structural burdens that hindered maintainability and copy-into-app usability:

1. **DTCG 2025.10 as editing source of truth**: Five of six themes were authored in TypeScript generators (`scripts/theme/*.ts`), encoded into 42 W3C DTCG JSON files (requiring `$extensions` workarounds for `null`, `"none"`, tuples, and `colorOp`), and recompiled back into `theme.json` + `semantics.json`.
2. **Three overlapping layers with heavy translation glue**: Visual styling spanned a 58-key `theme.json`, 15 `finish` layers (`finish-fields.ts` allowlists + `Proxy` in `theme.ts`), and 76 nested `controls` slots (`packages/ui/lib/look.ts` with 720 lines of `SlotFace`/`Fill` indirection). 23 of the 76 control slots served only a single theme.
3. **Redundant and domain-specific tokens**: `theme.json` forced every theme to declare `sidebar-*` (8 keys; 5 unused, 3 aliased), 4 `*-foreground` aliases, 5 `*-tint` formula keys, 5 `chart-*` keys, and 11 single-surface/control tokens (`brand-edge`, `focus-inner`, `knob`, `inverse*`, `hover`, `inset`, `raised`, `field`, `track`), while disallowing optional `font-sans` / `font-mono` overrides (`0009`). Status colors carried upstream brokerage terms (`up`, `warn`) alongside standard ones (`info`, `destructive`).

## Decision

Adopt **Theme v5**, centering on a single orthogonal TypeScript source model and minimal runtime/CLI outputs:

1. **TypeScript Sparse Inheritance as the Single Source of Truth**:
   - `packages/theme/schema.ts` defines `ThemeSpec`, `ThemePatch`, `SurfaceSpec`, `FeedbackSpec`, `MotionSpec`, `ControlsSpec`, and `defineTheme()`.
   - `packages/theme/themes/nsh-gallery/index.ts` defines the complete `base` theme; the remaining five themes (`shadcn`, `solid-glass`, `apple`, `material`, `winui`) are single sparse TypeScript files declaring only their deltas from `base`.
   - W3C DTCG (`{light,dark}.tokens.json`), `DESIGN.md`, and `theme.json` become **one-way build exports** generated by `bun run tokens:build` directly from the TypeScript themes. Delete `packages/theme/tokens/`, `semantics.json`, `finish-fields.ts`, and bidirectional DTCG generators.

2. **Minimal 25-Key `theme.json` & Standardized Semantic Names**:
   - `cssVars.theme` exposes optional `font-sans` / `font-mono` (omitted by default in built-in themes, honoring system fonts unless customized by a theme or host app) plus `radius` (mirrored from `radius-control`), `radius-control`, `radius-container`, `radius-modal`, `scrim`, `media`, `on-media`.
   - `cssVars.light` / `cssVars.dark` carry 21 core semantic roles (`background`, `card`, `popover`, `muted`, `surface`, `foreground`, `muted-foreground`, `faint`, `primary`, `primary-foreground`, `secondary`, `accent`, `brand` defaulting to `var(--primary)`, `border`, `line`, `input`, `ring`, `info`, `success`, `warning`, `destructive`).
   - Rename `up` → `success` and `warn` → `warning` across tokens, `colors`, `tints`, and `Tone` (`Stat` maps trend props `up`/`down` to `success`/`destructive` internally).
   - Remove `sidebar-*` completely from `theme.json` and `Palette` (`sidebar` and `split-view` read `background`, `accent`, and `line`); remove `*-foreground` overrides (Material degrades `secondary`/`accent` text to `foreground`, verified WCAG AA), `*-tint` top-level tokens (computed reactively via `tintAlpha`), `chart-1..5` required keys (derived from `[brand, info, success, warning, destructive]` unless overridden), and surface-private keys (`brand-edge`, `focus-inner`, `knob`, `inverse*`, `hover`, `inset`, `raised`, `field`, `track`).

3. **Orthogonal 4-Layer Semantics & Single-Theme Slot Pruning**:
   - **Surfaces (`surfaces`, 11 roles)**: `card`, `raised`, `inset`, `channel`, `plate`, `overlay`, `modal`, `inverse`, `glass`, `accent`, `fill` sharing one plain `SurfaceSpec` interface (no `finish-fields.ts`, no `Proxy`, no hidden non-enumerable properties). State layers (`hover`, `pressed`, `disabled`) and `knob` move to `feedback` and `controls`.
   - **Feedback (`feedback`)**: Unifies `hover`, `press` (extensible with `scale`, `translateY`, `overlay`, `surface`, `accent`), `focus`, `disabled`, and `passive` opacities.
   - **Motion (`motion`)**: Keeps CSS-safe timings (`state`, `fast`, `default`, `slow`), adds optional `spring` channel and extensible scene `presets` (`popoverEnter`, `dialogEnter`).
   - **Controls (`controls`)**: Prune single-theme outliers that do not generalize across themes:
     - Drop 4 groups: `tooltip` (all use `surfaces.inverse`; `shadcn` styles `inverse` as inverted high-contrast bubble), `toast` (actions use shared `accent`), `calendar` (today uses subtle `foreground` wash), `disabled` (merged into `feedback.disabled`).
     - Drop 14 single-theme slots: `button.secondary.{ink,hover}`, `field.disabled.face`, `spinner.spokes`, `progress.line`, `choice.{halo,mark.hover,mark.pressed}`, `slider.{mark.hover,mark.pressed,brightens}`, `switch.knob.hover`.
     - Replace 2 slots with structural rules: `field` bottom radius auto-zeroes when `edges === "bottom"`; ring-only `RadioRing` uses `primary` stroke when active.
     - Explicitly retain two numerical degenerate slots with clear cross-theme semantics: `controls.switch.knob.on` (Material on-knob growth, default `"same"`) and `controls.slider.mark` (WinUI ring inner dot diameter, default `0`).

4. **Unified Runtime & Lean Copy-into-App Distribution**:
   - Consolidate `@shadcn-nsh/theme` (`theme.ts`) and `packages/ui/lib/look.ts` / `press.ts` into a single direct API (`colors`, `tints`, `chart`, `shape`, `metrics`, `surface()`, `feedback`, `motion`, `control()`), removing `look.ts`.
   - `shadcn-nsh init --theme <id>` installs `theme.json` and `DESIGN.md` at the app root plus lean TS theme modules under `lib/ui/` (omitting `light.tokens.json`, `dark.tokens.json`, and `semantics.json`). `shadcn-nsh add theme-<id>` installs a single `themes/<id>.ts` file.

## Consequences

- Defining a new theme requires one concise TypeScript file overriding only the tokens, surfaces, or controls that differ from `base`.
- Adding a new press feedback primitive, motion preset, or shared control slot requires editing one schema/runtime location with neutral defaults; existing themes inherit automatically without edits.
- Components remain 100% theme-agnostic and reactive under `selectTheme()` with roughly 75% less runtime glue code.
- `packages/ui/lib/` consolidated from 16 files / 15 registry entries into 8 cohesive modules (`utils.tsx`, `state.ts`, `motion.tsx`, `surface.tsx`, `field-look.ts`, `icons.tsx`, `popup.tsx`, `listbox.tsx`), removing `track.ts` and folding `switch-geometry.ts` into `switch.tsx`.
