## One look, more than one palette

A theme is one `AppTheme`: `theme.json` (its tokens: colours and radii), `finishes.json` (the
surfaces it draws: gradients, shadows, edges) and the `index.ts` that names it. An app is _built_
with one theme and can _carry_ more, switching between them while it runs with `selectTheme`.

Every demo on this site can be drawn in any of these palettes: pick one with the **Demo theme**
switch in the nav, and the previews load again in it. The panel above is the showcase — buttons, a
card with a field, badges, switches, a slider and a progress bar, with the card, inset and press finishes
the palette brings. The list is `apps/website/demos/palettes.ts`. Each palette has its own page,
with the same sections: how to install it, every token it sets, and every finish it draws. Those
pages read each theme's `theme.json` and `finishes.json`, and the layers they group tokens by and
the duties they report for a finish are the [theme spec](https://github.com/aningdev/shadcn-nsh/blob/main/docs/specs/theme-roles.md)'s.

## One radius, three tiers

A theme states one base length, `radius`; `radius-control` is 0.8× it and `radius-card` is 1.4×,
each rounded to whole points. The default theme's base is 10, so controls are 8 and cards are 14; a
dialog takes the card tier. Every corner that reads a theme radius uses the continuous curve, which
`rounded()` applies in one place.
