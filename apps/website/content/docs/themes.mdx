## One look, more than one palette

A theme is one `AppTheme`: the TypeScript spec `defineTheme()` compiles — tokens, metrics, elevation,
eleven surfaces, feedback, motion and controls — and the `theme.json` that same build exports from it
(the roles of both appearances, three `radius-*` layer lengths and the fixed `scrim` / `media` /
`on-media` values). A theme that ships beside another is a sparse delta over it, so it states only
what it changes. An app is _built_ with one theme and can _carry_ more, switching between them while
it runs with `selectTheme`.

Every demo on this site can be drawn in any of these palettes: pick one with the **Demo theme**
switch in the nav, and the previews load again in it. The panel above is the showcase — buttons, a
card with a field, badges, switches, a slider and a progress bar, with the card, inset and press surfaces
the palette brings. The list is `apps/website/demos/palettes.ts`. Each palette has its own page,
with the same sections: how to install it, every token it sets, and every surface it draws. Those
pages read each theme's own spec. The contract is
[`docs/theme.md`](https://github.com/aningdev/shadcn-nsh/blob/main/docs/theme.md).

## Radii by role

`theme.json` states one corner radius per layer in `cssVars.theme` — `radius-md` (in-page
elements), `radius-lg` (cards, menus, popovers, toasts) and `radius-xl` (dialogs, sheets) —
and `control("button").corner.*` makes buttons capsules (`material`, touch `apple`) or points / `control` (the rest). A surface nested in
another takes the concentric corner, `rounded(outer, inset)`. Every corner that reads a theme radius
uses `shape.curve` (`"continuous"` or `"circular"`), which `rounded()` applies in one place.
