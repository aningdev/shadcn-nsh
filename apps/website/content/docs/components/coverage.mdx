<a href="https://ui.shadcn.com/docs/components">shadcn/ui components</a>, whose parts and API names
this library follows, and the <a href="https://nsh.dev/elements">NSH elements</a> it is built on.
Each table lists every component of theirs and where it went here: a page under another name counts,
and a row with no page says why there is none.

This page is generated from `apps/website/src/lib/official.ts`; do not edit it. Add a component there,
then run `bun run docs:components`. Its NSH rows are also what makes a page _Official_ on{" "}

<a href="/docs/components">Components</a>: a page named in one of them is aligned with an NSH
element, and a page named in none is this library's own. `bun run check:pages` fails when an
official component has no row, when a row names a page that does not exist, and when a row serves
nothing without saying why.
