FAQ

Is this an official NSH project?+

No, it is a community project. Behavior, keyboard and accessibility come from NSH's own nsh/base, unchanged; the look starts from NSH's official example UI and is owned and maintained here.

How does it relate to shadcn/ui? Can I use it in a React web app?+

It follows shadcn/ui's model — a registry, a CLI, one file per component, and parts named Trigger, Content, Item — but the components draw NSH native views, not the DOM, so they don't run in a React DOM app. An NSH app reaches the browser through NSH's web target, which is how every demo on this site runs.

Why copy files instead of installing a package? How do I get updates?+

add writes the component, its theme and the looks it imports into your app, then forgets them: there is no runtime package of ours to keep in sync, and the files are yours to change. npx shadcn-nsh@latest diff shows which copies differ from the registry; add <name> --overwrite writes the new version over yours.

Which platforms does it run on?+

Wherever NSH does: iOS, Android, macOS, Windows, Linux, the web and the terminal. Each component adapts its density and controls to a touch screen, a pointer and a keyboard.

Which NSH version do I need?+

Each release tracks one NSH CLI version — 0.9.x is written against v0.6.1. The compatibility table lists them all.

Which themes are there? Can I make my own?+

Six ship: default, shadcn, solid-glass, apple (Liquid Glass on macOS and iOS 26), material (Material 3 Expressive on Android), and winui (WinUI 3 on Windows); native picks apple on Apple platforms, material on Android, winui on Windows, and default elsewhere. Choose one with init --theme, add more with add theme-<name> and switch at run time with selectTheme. A theme is one TypeScript spec — defineTheme() over the theme it extends, with theme.json as its build export — so yours is an edit away. See Themes.

Does it work with AI coding assistants?+

Every docs page is also Markdown: add .md to its URL. /llms.txt indexes them and /llms-full.txt holds them all in one file.

What is the license?+

MIT. The copied files are yours, with no runtime dependency on this project.
